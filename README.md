# Mounir Academy Smart LMS | منصة أكاديمية منير الذكية

نظام إدارة تعليمي متكامل ومخصص للأكاديميات التعليمية ومراكز تحفيظ القرآن والمسارات التربوية، مبني وفق أحدث معايير الأداء والواجهات الاحترافية (Corporate SaaS) مع الحفاظ على أعلى درجات الخصوصية وسهولة الاستخدام.

---

## 🌟 المميزات والأنظمة الرئيسية (Core Modules)

### 1. 🎓 بوابة الطالب وولي الأمر (student.html)
- **كارت الطالب الذكي ورمز QR:** بطاقة رقمية موحدة لكل طالب تتضمن كود الطالب وحالة الاشتراك والباركود.
- **محرك حصص القرآن الكريم الفردية:** عداد رصيد الحصص المتبقية (4 حصص لكل تجديد)، تنبيه فوري عند بقاء حصة واحدة أو أقل، وعرض موضع التلاوة والحفظ (السورة والآية).
- **نظام البلوكات الرباعية للمحاضرات (4-Lecture Blocks):** فتح المحاضرات (1-4) تلقائياً، وقفل المحاضرات (5-8) حتى تجديد الاشتراك لضمان التحصيل المالي.
- **الاختبارات والتقييمات التفاعلية:** تصحيح فوري متعدد الاختيارات (MCQ) واحتساب النسبة المئوية واعتماد نتيجة الاختبار.
- **تذاكر الدعم الفني والاستفسارات:** تقديم تذاكر دعم بمختلف التصنيفات ومتابعة ردود إدارة الأكاديمية فورياً.
- **إضافة المحاضرات لتقويم Google:** توليد روابط Google Calendar بضغطة زر لجدولة المواعيد.
- **إيصالات الدفع الإلكتروني:** إيصال سداد رقمي فوري مع إمكانية المشاركة عبر واتساب (wa.me).

---

### 2. 👨‍🏫 بوابة المعلمين والمدربين (	eacher.html)
- **نظام الخصوصية المشددة (Privacy Masking):** حجب أرقام هواتف أولياء الأمور وتكلفة الاشتراكات لحماية خصوصية العائلات والطلاب.
- **سجل الطلاب ومتابعة القرآن:** تسجيل حضور الجلسات، خصم الكريدت، إدارة الأعذار (العذر الأول مجاني)، وتحديث السورة والآية مع ملاحظات التجويد.
- **كشف المستحقات والتسويات المالية للمعلم:**
  - حساب فوري للمستحقات: (عدد الحصص المنفذة × سعر الحصة المعتمد).
  - عرض إجمالي المسحوبات والرصيد المستحق الحالي للصرف.
  - جدول تفصيلي بسجل الحوالات والتسويات الصادرة للمعلم (رقم السند، تاريخ التحويل، الطريقة).

---

### 3. ⚙️ لوحة الإدارة الشاملة (dmin.html)
- **مركز سعة المجموعات ومتابعة الفئات العمرية:**
  - رصد دقيق للأعمار الفعلية للطلاب المقيدين في كل مسار ومعدل متوسط السن (Average Age).
  - تنبيه فوري للمجموعات غير المكتملة مع شريط توضيحي لعدد المقاعد الشاغرة.
  - نافذة تعديل الحدود العمرية والسعة القصوى والمدة الافتراضية لكل كورس.
- **محرك رواتب ومحاسبة المعلمين (Teacher Payroll Engine):**
  - جدول موحد لحساب أتعاب جميع المعلمين وصافي الرصيد المستحق لكل منهم.
  - نافذة "تسوية المستحقات" لتسجيل الدفعات (فودافون كاش / إنستاباي / بنك) وإصدار أرقام السندات.
- **سجل التزام وأداء المعلمين (Scorecard):**
  - إحصاء دقيق لحالات الإلغاء، التأخر عن الحصص، ونسبة تسرب الطلاب.
  - مؤشر التزام تراكمي محسوب بنسبة مئوية (% Commitment Score).
- **راصد الطلاب المتوقفين والمنقطعين:**
  - تتبع آلي للطلاب منتهي الرصيد أو المتغيبين لأكثر من 3 حصص متتالية.
  - زر تواصل مباشر عبر واتساب بنص ترحيبي مهيأ باسم الطالب وولي الأمر للمتابعة والتجديد فوراً.
- **مرونة مدة المحاضرات:**
  - إمكانية تعديل مدة أي محاضرة بنقرة واحدة (30، 45، 60، 90، 120 دقيقة) من جدول المحاضرات.
  - تسجيل مدة تواجد الطلاب الفعلية عبر Google Meet.
- **التأجيل وإعادة الجدولة الجماعية (Bulk Reschedule):**
  - تعديل مواعيد المسارات وإرسال إشعارات فورية للطلاب مع عذر معتمد دون احتساب غياب.
- **تصدير شيتات Excel المباشرة:**
  - تصدير شيت الحضور التلقائي (/api/admin/export/attendance-excel).
  - تصدير بيانات الطلاب والمسارات بالكامل (/api/admin/export/students-excel).

## 🛠️ البنية التقنية (Tech Stack)

- **Backend:** FastAPI (Python 3.10+)
- **Database:** SQLite3 مع نظام ترقية تلقائي للـ Schema (Automatic Migrations).
- **Frontend:** Modern Semantic HTML5, TailwindCSS (CDN), Vanilla JavaScript.
- **Integrations:** Google Meet, Google Calendar, Paymob Checkout Simulator, WhatsApp Direct API.
- **Exporting:** OpenPyXL (Excel Engine).

## 🚀 كيفية التثبيت والتشغيل المحلي (Quick Start)

### 1. المتطلبات الأساسية
- تثبيت Python 3.10 أو أحدث.
- توفر Git.

### 2. تثبيت الحزم المطلوبة
`ash
pip install -r requirements.txt
`

### 3. تشغيل السيرفر
يمكنك تشغيل المنصة مباشرة عبر الملف المساعد:
- الضغط المزدوج على un_server.bat
- أو تشغيل الأمر التالي من موجه الأوامر:
`ash
cd backend\app
python -m uvicorn main:app --host 127.0.0.1 --port 8000 --reload
`

### 4. الروابط المباشرة بعد التشغيل
- **الصفحة الرئيسية:** [http://127.0.0.1:8000/](http://127.0.0.1:8000/)
- **بوابة الطالب:** [http://127.0.0.1:8000/student.html](http://127.0.0.1:8000/student.html)
- **بوابة المعلم:** [http://127.0.0.1:8000/teacher.html](http://127.0.0.1:8000/teacher.html)
- **لوحة الإدارة:** [http://127.0.0.1:8000/admin.html](http://127.0.0.1:8000/admin.html)
- **التوثيق التفاعلي للـ API (Swagger):** [http://127.0.0.1:8000/docs](http://127.0.0.1:8000/docs)
